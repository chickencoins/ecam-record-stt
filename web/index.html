음성 인식은 무료로 이 PC에서 처리합니다. 기본은 GPU 우선이며, 호환 GPU 실행 환경이 없으면 CPU로 전환합니다. GPU 라이브러리는 EXE에 포함하지 않습니다.

문장이 이어지는 조각은 합칩니다. 선택한 길이가 지나도 문장이 끝난 뒤에 줄을 바꾸며, 시간은 문단 앞에 한 번만 표시합니다.

선택한 탭의 표시 영역을 PNG로 저장합니다. 다른 창이 가려도 해당 창은 찍히지 않습니다. 페이지를 아래로 스크롤하면 스크롤한 위치가 저장됩니다.
